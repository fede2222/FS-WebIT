Process vs Thread

Experimento mínimo para visualizar que un proceso puede contener múltiples threads de ejecución.

Concepto a fijar: el proceso es la instancia del programa con sus recursos y memoria; dentro de ese proceso pueden existir varios threads que comparten esos recursos y ejecutan trabajo de forma independiente. En este lab se imprime el Process ID y los IDs administrados por .NET de tres threads creados explícitamente.
